# حساب‌یار ۲

پروژه قابل ساخت در همین پوشه است؛ فایل‌های base64 و پوشه‌های override فقط سابقه نسخه قبلی‌اند و در ساخت نسخه ۲ استفاده نمی‌شوند.

## امکانات
- تشخیص بانک با سرشماره دقیق، نام فرستنده و عنوان ابتدای پیامک؛ تعریف دستی سرشماره هر صندوق محلی.
- ورود اختیاری تاریخچه با بازه شمسی (شامل روز شروع و پایان)، یا فقط آخرین پیامک دارای مانده برای هر حساب.
- ساخت خودکار حساب‌ها؛ شناسه کامل حساب به همراه بانک مانع ادغام حساب‌های دارای چهار رقم آخر یکسان می‌شود.
- ریال در ذخیره‌سازی، ورودی‌ها، گزارش‌ها و خروجی فایل بانکی؛ تبدیل یک‌باره دیتابیس نسخه ۱ از تومان به ریال.
- حذف تراکنش و سهم اشخاص وابسته، با جلوگیری از بازگشت پیامک حذف‌شده در اسکن مجدد.
- مستثناکردن حساب از موجودی کل، گزارش‌ها، مانده مرتبط اشخاص و ثبت خودکار پیامک.
- «حساب اشخاص»: تعریف شخص، ثبت طلب/بدهی/تسویه، ریز گردش و حذف گردش.
- رابط راست‌چین جدید، تقویم شمسی و حالت روشن/تاریک.

## رفتار موجودی
مانده اعلام‌شده در پیامک یک نقطه مبناست. تراکنش‌های قدیمی‌تر از آن در تاریخچه نمایش داده می‌شوند ولی دوباره روی مانده جمع نمی‌شوند. فقط تراکنش‌های بعد از مبنا در موجودی اثر می‌گذارند. حذف تراکنش پیش از مبنا، مانده واقعی اعلام‌شده بانک را تغییر نمی‌دهد. ورود «فقط آخرین مانده» تراکنش تاریخی ایجاد نمی‌کند.

وقتی پیامک شناسه حساب ندارد، یک حساب با عنوان «بدون شناسه» برای همان بانک و فرستنده ساخته می‌شود؛ امکان تفکیک چند حساب آن بانک بدون شناسه در پیامک وجود ندارد. کارت و حساب با شناسه‌های متفاوت بدون مدرک به یکدیگر وصل نمی‌شوند.

## پوشش بانک‌ها و محدودیت
فهرست داخلی نام ۳۷ بانک/مؤسسه/صندوق و نام‌های تاریخی برای ورود پیامک‌های گذشته را می‌شناسد. سرشماره عددی برای همه مؤسسات و صندوق‌های ثبت‌شده به‌صورت عمومی و قابل راستی‌آزمایی در دسترس نیست؛ ادعای پوشش کامل وجود ندارد. نام‌های تاریخی در فهرست، ادعای مجوز فعالیت فعلی نیستند. سرشماره‌های عددی شناخته‌شده با تطبیق دقیق استفاده می‌شوند؛ هیچ تطبیق پیشوندی خطرناک انجام نمی‌شود. برای ناشناخته‌ها بخش مدیریت سرشماره وجود دارد. پیامک رمز و تبلیغات فاقد مبلغ مالی وارد نمی‌شوند. واحد بدون برچسب در پیامک بانک، ریال فرض می‌شود.

سرشماره‌ها نشانه‌ای برای دسته‌بندی محلی‌اند و گواهی اصالت پیامک نیستند. هر مؤسسه تازه را می‌توان بدون اتصال اینترنت با سرشماره اختصاصی افزود.

## ساخت و آزمون
Java 17، Gradle 8.13، Android SDK 36:

```
gradle testDebugUnitTest assembleDebug
gradle connectedDebugAndroidTest
```

گردش کار `HesabYar v2 verified APK`، تست واحد، ساخت، بررسی امضا و آزمون دیتابیس روی شبیه‌ساز اندروید را انجام می‌دهد. APK این گردش کار debug است. کلید نسخه قبلی در مخزن وجود ندارد؛ اگر امضاها متفاوت باشد ارتقای مستقیم ممکن نیست. قبل از حذف نسخه قبلی، از اطلاعات مالی نسخه موجود نگهداری کنید.
